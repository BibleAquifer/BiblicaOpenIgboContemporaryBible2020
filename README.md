# _Biblica® Open Igbo Contemporary Bible 2020_ Aquifer Resource

This repository (`BiblicaOpenIgboContemporaryBible2020`) contains an Aquifer Bible resource with resource-level metadata and content files in USFM and USX formats.

## Structure

The repository is organized by language codes, with each language folder containing USFM and USX content files.
